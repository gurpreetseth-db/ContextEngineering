Failure modes

Four ways context fails

Poisoning

A false fact becomes a premise

Fix: remove or block the source.

Distraction

Valid context buries the task

Fix: scope, clear, or compact.

Confusion

The wrong source or tool is used

Fix: fewer candidates, sharper metadata.

Clash

Context elements disagree

Fix: set precedence and one source of truth.

Domain 2

Include an example only if it earns its tokens

Include when it

  • Covers an untested tool path
  • Shows the required output structure
  • Resolves an ambiguous request
  • Demonstrates a refusal

Exclude when it is

  • Redundant or near-duplicate
  • Stale or low-frequency
  • Easy to infer from instructions

The longest prompt is not the winner.
