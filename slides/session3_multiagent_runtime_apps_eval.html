Multi-agent design

Send a bounded packet, not the whole trace

Down to a sub-agent

  • Subtask and success criteria
  • Global constraints
  • Authoritative source references
  • Prior decisions and freshness marker

Back to the coordinator

  • Result and confidence
  • Source ids and assumptions
  • Blockers
  • A small structured payload

Evaluation loop

01Define the task and failure modes
02Build a set with traps
03Instrument traces
04Choose scorers
05Run a baseline
06Change one lever
07Read the failing traces
08Promote on evidence, then monitor
